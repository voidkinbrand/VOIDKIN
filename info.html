Can I pay on this website?

No. The current website displays the collection and opens a Telegram inquiry. No bank card data is collected, and no payment occurs here.

Is my size in stock?

Stock has not been verified. The listed sizes are preliminary. Confirm availability and actual garment measurements with VOIDKIN before paying.

How much does shipping cost?

Shipping terms depend on your destination. Ask for a written quote, dispatch estimate and delivery method before completing an order.

Do Telegram links confirm an order?

No. The link can pass an item code and size to @voidkin_bot, but processing depends on the bot configuration. A purchase is only agreed when VOIDKIN confirms the details directly.

Where can I see product details?

Every product has a separate item page with the original photographs, print details, available reference views and a size inquiry action.
